**《伴读智汇》名著阅读智能陪练平台 PRD 规划稿**

一、产品概述

1.1 产品名称

伴读智汇

1.2 一句话定位

面向 K12 与高校语文整本书阅读的智能陪练平台，通过记录学习行为数据，精准推送思辨题与拓展阅读，动态规划阅读节奏，帮助学生从"读完"走向"读懂、读深、读思"。

1.3 产品形态

学生端：Web ，支持响应式。

教师端：Web 工作台。

管理后台：Web，供教研、运营、管理员使用。

1.4 核心价值

对学生：个性化阅读计划、AI 陪练、思辨训练、拓展阅读、成长档案。

对教师：布置整本书阅读任务、查看班级学情、精准干预、减负增效。

对学校/机构：整本书阅读数据看板、校本资源、教学质量管理。

1.5 业务闭环

注册登录 → 身份与学段选择 → 选书/加入课程 → 能力与兴趣测评 → 生成动态阅读计划 → 每日阅读与任务 → 行为数据采集 → AI 分析 → 推送思辨题与拓展阅读 → 练习反馈 → 调整节奏 → 周报/月报 → 教师查看。

4.1 登录注册模块

手机号验证码登录

账号密码登录

学号/邀请码登录，适用于教师布置班级场景

4.1.2 注册流程

1\. 进入启动页。

2\. 选择注册/登录。

3\. 输入手机号，获取验证码。

4\. 设置密码，同意用户协议与隐私政策。

5\. 选择身份：学生 / 教师。

6\. 学生选择学段：小学 / 初中 / 高中。

7\. 填写年级、学校、班级邀请码，可跳过。

8\. 选择阅读目标：应试提分、兴趣拓展、思辨写作、通识素养。

9\. 完成兴趣标签：文学、历史、哲学、科幻、传记等。

10\. 进入首页或身份对应工作台。

4.1.3 特殊规则

未成年人：需监护人同意，展示未成年人隐私保护提示。

异常：验证码错误、频繁请求、账号封禁、网络失败，均给出明确提示。

4.1.4 登录后路由

4.2 课程学习模块

4.2.1 课程/书目列表

推荐课程：根据学段、目标、兴趣推荐。

我的课程：已加入、进行中、已完成。

班级课程：教师布置。

书单：教育部推荐、新课标、高校通识、校本。

筛选：学段、体裁、难度、主题、字数、预计时长。

4.2.2 课程详情页

封面、书名、作者、版本、简介。

阅读目标、核心主题、思辨方向。

目录与章节进度。

任务列表：导读、章节测、思辨题、拓展阅读、读后感。

讨论区：班级讨论、教师置顶。

按钮：开始阅读 / 继续阅读 / 加入课程。

4.2.3 阅读器

翻页/滚动模式。

目录、进度条、章节切换。

字号、背景、护眼模式、夜间模式。

划线、批注、摘抄、书签。

查词、百科、AI 解释。

阅读计时、进度同步、离线缓存。

AI 陪练入口：可提问、追问、总结、人物关系梳理。

4.2.4 学习任务

导读任务：背景、作者、阅读策略。

章节任务：章节测、人物分析、情节梳理。

思辨题：开放题、对比题、证据题。

拓展任务：同主题文本、文献、影视、音频。

读后感/小论文：支持草稿、提交、AI 反馈、教师评阅。

4.2.5 完成与反馈

提交后生成即时反馈：理解度、思辨力、文本证据使用。

教师可批改、评分、推荐优秀作业。

完成后获得成就、证书、积分。

自动更新阅读计划与推荐。

4.3 智能陪练与思辨推送

4.3.1 AI 陪练

苏格拉底式追问：为什么？依据是什么？还有别的可能吗？

提示分级：轻提示、中提示、详细解析。

角色陪练：作者视角、人物视角、批判者视角。

对话记录保存到个人中心。

4.3.2 思辨题推送

依据：课程进度、答题正确率、停留时长、回看次数、批注质量、错题标签。

题型：观点辨析、因果分析、人物评价、主题比较、现实迁移。

难度：基础、进阶、挑战。

推送时机：完成章节后、每日任务中、周报后。

频次控制：每日不超过 3—5 题，避免打断阅读。

4.3.3 拓展阅读推送

同作者、同主题、同时代、同体裁。

背景资料、评论文章、学术入门、影视片段。

支持一键加入书架或计划。

4.4 学习行为分析与动态节奏

4.4.1 采集数据

阅读时长、页数、速度、章节完成率。

回看、暂停、跳出、划线、批注、摘抄。

答题正确率、修改次数、AI 对话轮次。

收藏、分享、讨论、任务提交时间。

设备、时段、连续天数。

4.4.2 分析维度

投入度：时长、连续天数、任务完成率。

理解度：章节测、思辨题、文本证据。

思辨力：观点复杂度、反驳能力、迁移能力。

坚持度：计划完成率、中断恢复。

偏好：题材、作者、题型、拓展类型。

4.4.3 动态阅读节奏

初始计划：根据学段、字数、可用时间生成。

每日目标 = 基础页数 × 近期完成率系数 × 理解度系数 × 可用时间系数。

连续未完成：自动减量、拆分任务、降低难度。

高投入高理解：增加拓展、挑战题、讨论任务。

用户可手动调整"轻松/标准/冲刺"模式。

六、核心业务流程

6.1 学生核心流程

登录注册 → 身份学段 → 选书/加入课程 → 初始测评 → 生成计划 → 每日阅读 → 行为采集 → AI 分析 → 推送思辨题/拓展 → 提交反馈 → 调整计划 → 周报。

6.2 教师核心流程

登录 → 认证 → 创建班级 → 选书/布置任务 → 学生完成 → 查看学情 → 干预/评阅 → 导出报告。

6.3 动态调整流程

数据采集 → 能力评估 → 推荐引擎 → 计划调整 → 用户确认/自动执行 → 效果回流。

七、交互逻辑

1\. 一致性：底部导航、卡片、按钮、返回逻辑统一。

2\. 少打断：阅读中不弹强提醒，任务以浮层/角标提示。

3\. 渐进式：注册分步，阅读任务由易到难。

4\. 可撤销：批注、答题、计划调整支持撤销或修改。

5\. 及时反馈：提交后 1—3 秒内给出 AI 反馈或"批改中"。

6\. 空状态：无课程、无笔记、无消息时给出引导按钮。

7\. 错误处理：网络失败可重试，数据本地缓存。

8\. 通知：任务提醒、教师评价、周报，可配置免打扰。

9\. 多端同步：阅读进度、笔记、答题实时同步。

九、 推荐与节奏算法

冷启动：学段+目标+兴趣标签+教师布置。

规则层：课程进度、错题、弱项、时间。

模型层：协同过滤 + 知识追踪 + LLM 语义分析。

节奏公式：每日页数 = 基础页数 × 完成率系数 × 理解系数 × 可用时间系数。

思辨题推送：弱项优先、文本证据优先、难度递进、频次控制。

十、非功能与合规

性能：首屏 < 2s，阅读器翻页 < 200ms。

安全：HTTPS、数据加密、权限分级、日志审计。

隐私：未成年人监护人同意，最小化采集。

版权：书目、拓展内容需正版授权。

AI 安全：内容审核、幻觉提示、教师复核。

无障碍：字号调整、色弱模式、键盘导航。

十二、成功指标

注册转化率 ≥ 60%。

课程完读率 ≥ 50%。

思辨题提交率 ≥ 70%。

7 日留存 ≥ 35%，30 日留存 ≥ 20%。

教师周活 ≥ 40%。

推荐点击率 ≥ 15%。

十三、补充建议

1\. 强化"整本书"而非碎片阅读：以书目为单元，章节为节点，主题为线索。

2\. 思辨题必须绑定文本证据，避免空泛讨论。

3\. 动态节奏要"可解释"，让学生知道为什么调整。

4\. 教师端要减负，不要变成第二个批改系统。

5\. AI 陪练需有边界：不直接给答案，优先追问与提示。

6\. 建立书目知识图谱：人物、情节、主题、手法、背景、拓展。

7\. 关注版权与未成年人合规。
