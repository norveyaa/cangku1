# 伴读智汇 · 前端原型（MVP P0）

面向 K12 与高校语文整本书阅读的智能陪练平台 —— 学生端 + 教师端 Web 前端原型。
依据 [001-产品PRD/prd第八组(3).md](../001-产品PRD/prd第八组(3).md) 开发，视觉规范对齐 [002-UI界面（美术设计）](../002-UI界面（美术设计）/index.html)（个人成长中心页面）。

## 快速开始

直接用浏览器打开 `index.html` 即可，**无需构建、无需联网**（纯静态 HTML/CSS/JS，数据存于 localStorage）。

## 技术说明

- **架构**：多页静态站点 + 共享数据层。`assets/js/store.js` 提供 mock 数据与 localStorage 持久化（阅读进度、划线批注、错题、任务提交、教师任务等在页面间实时一致）。
- **路由守卫**（PRD §8）：未登录访问学习页 → 重定向 `index.html?redirect=原路径`；学生访问教师页 → `403.html`。
- **图表规范**：`assets/js/charts.js` 按 dataviz 方法论实现——单序列品牌墨蓝 `#1F3A5F`（暗色 `#4E86C8`）、双序列 `#4E86C8 + #C87F2E`（经六项检查验证，见 `tools/palette-check.mjs`）、顺序色阶热力图、悬停提示、每图附数据表视图（无障碍通道）、随站点夜间模式切换。
- **响应式**：桌面优先，≤900px 折叠搜索框，≤640px 收紧布局。
- **内容合规**：公有领域作品（老舍、鲁迅、吴承恩等，作者逝世超 50 年）收录短节选；非公版书目（《乡土中国》《繁星·春水》）仅用原创梗概，并标注"正式版本将收录正版授权的完整文本"。
- **数据重置**：浏览器控制台执行 `Store.reset()` 可恢复初始演示数据。

## 演示数据口径

- 周阅读时长 `[90, 38, 0, 0, 0, 0, 0]` 与设计稿"本周已读 128 分钟"一致；能力四维 82/76/68/88 与设计稿一致。
- 思辨题提交强制要求引用文本证据（PRD 补充建议 2）；每日思辨推送限 3—5 题（PRD 4.3.2 频次控制）。
- AI 陪练为关键词规则的演示实现（不直给答案，优先追问），正式版接入 LLM。
